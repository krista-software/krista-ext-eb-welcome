## Version 1.0.0 (November 2026)

Initial release of the EB Welcome extension. Built against Krista Service APIs Java 1.0.126.

### New Features
* **Generate Welcome Message** — composes a personalized welcome/greeting message for a named
  recipient, with an optional custom template. Self-contained; no external system or credentials.
* **Test Connection** / **Health Check** — standard Setup-area checks confirming the extension is
  loaded and running.
