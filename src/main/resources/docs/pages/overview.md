# Overview

EB Welcome is a self-contained Krista extension that composes a personalized welcome/greeting
message. It calls no external system and needs no credentials — the message is generated entirely
inside the extension from the inputs you provide, so it can be used in any workflow that needs to
greet or welcome someone by name.

## Use cases

- **Onboarding a new user or employee** — generate a friendly greeting to include in a workflow's
  notification, email, or chat step.
- **Testing/demo workflows** — a lightweight, no-setup request for building and validating Krista
  workflows that need a simple text-generation step.

## What you can do

The extension exposes 3 requests across 2 areas — see [Supported Requests](pages/supported-requests.md)
for the full list, or the sidebar for each request's detailed page.

## Before you start

1. There is no authentication to configure — see [Authentication](pages/Authentication.md).
2. Nothing to configure on the Setup tab — see [Configuration](pages/ExtensionConfiguration.md).
3. Run **Test Connection** (Setup area) to verify the extension is loaded and operating normally.
