# Authentication

EB Welcome uses **no authentication**. It does not call any external system or API — the welcome
message is composed entirely from the inputs you pass to the request — so there are no credentials,
tokens, or scopes to obtain or configure.

## Obtaining credentials

Not applicable. There is nothing to create, request, or paste into a Setup-tab field.

## Required scopes / permissions

| Scope / Permission | Why it's needed |
|---|---|
| *(none)* | This extension has no external integration. |

## Verifying

Run **Test Connection** in the Setup area. Since there is no external system, a successful result
simply confirms the extension is loaded and running inside Krista.
