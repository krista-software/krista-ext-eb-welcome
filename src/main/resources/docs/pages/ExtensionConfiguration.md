# Configuration

EB Welcome has **no Setup-tab fields**. It calls no external system, so there is nothing to
configure — install the extension and its requests are immediately usable.

## Setup tab fields

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| *(none)* | -- | -- | This extension has no connection configuration. |

## Required vs optional

Not applicable — there are no fields to set or validate.

## Notes

- Each invoker needs nothing beyond installing the extension; there is no per-invoker credential or
  setting to maintain.
